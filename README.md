# Feizai React Site

A tiny React + Vite greeting site for `feizai.com`.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output will be in `dist/`.

## Put it on feizai.com

Deploy the repo to any static hosting provider (for example GitHub Pages, Cloudflare Pages, or Vercel), then add `feizai.com` as the custom domain and point the domain's DNS records to the values your host provides.

For an apex domain like `feizai.com`, the exact DNS records depend on the hosting provider, so use the provider's custom-domain screen rather than guessing A/AAAA/CNAME values.
